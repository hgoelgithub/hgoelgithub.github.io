Tutorials

Every notebook and script in the computational-science-tutorials repo — open notebooks in Google Colab with one click, no installation needed

This page mirrors the folder structure of the computational-science-tutorials GitHub repo — one section per top-level folder. Click Open in Colab to run any notebook instantly in your browser; Python scripts (.py) link to their source on GitHub instead.

TipRunning in Colab

Click any badge → sign in with Google → Runtime → Run All. All dependencies install automatically inside the notebook.

Note

A few folders keep working variants of the same tutorial (_copy, _advanced, and the Extra/ folder) alongside supporting data files. These are listed for completeness — start with the lowest-numbered notebook in each section.

Note

Found a bug or discrepancy? Please get in touch via email — feedback is always welcome.
